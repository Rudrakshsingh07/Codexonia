Terms of use

Use it to understand code.

Codexonia is a course project provided for educational use. These terms are intentionally short and written to be readable.

The service

Codexonia compiles and executes submitted Java code in an isolated sandbox and returns a structured execution trace. The service is intended for learning, debugging, and demonstrating how Java programs behave.

Acceptable use

You may submit code that you have the right to run. You may not use the service to:

  • Attack, probe, or escape the sandbox or the host environment.
  • Run malicious code, denial-of-service workloads, or cryptocurrency miners.
  • Process data you are not authorized to process.
  • Violate applicable law or the rules of your course or institution.

The sandbox has no network access, but you are still responsible for what you submit. The project team may restrict or stop the service if it is abused.

Your code

You retain ownership of the Java source you submit. By submitting it, you give the project permission to compile, execute, and trace it for the purpose of producing the requested run. The current build does not claim a persistent license to store or publish your source.

No warranty

Codexonia is provided as-is, without warranties of any kind. Execution may fail, traces may be incomplete, and the service may be unavailable. Do not rely on it for production, security-sensitive, or graded work where a failure would be harmful.

Limits

Runs are bounded by time, memory, output size, source size, file count, and event count. A limit hit is reported as a classified outcome. The current defaults are listed in the field guide.

Changes

The project may change these terms as the implementation evolves. The date at the top of this page records the last update.

Contact and attribution

Codexonia is a course project. See the About page for the project description and the privacy note for data handling.
