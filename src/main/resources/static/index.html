Anatomy of an event

A trace is not a log line. It is a state transition.

Every event carries the location, the frame, the change, and enough context to reconstruct what the program knew at that moment.

METHOD_CALL

Who entered what?

The call event captures the target method, its arguments, and the source line that triggered it.

{ "type": "METHOD_CALL", "class": "Sample", "method": "add", "args": ["2", "3"], "line": 4 }
ASSIGNMENT

What changed?

A variable gets a before and after, so the player can show the exact value transition and highlight the source line.

{ "type": "ASSIGNMENT", "var": "x", "old": "1", "new": "2", "line": 6 }
METHOD_RETURN

Where did it leave?

The return event closes the frame and carries the value back to the caller. The stack stays reconstructable at any step.

{ "type": "METHOD_RETURN", "class": "Sample", "method": "add", "ret": "5", "line": 4 }
