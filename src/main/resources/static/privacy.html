Privacy note

Privacy, in plain language.

Codexonia is a course project, not a student surveillance system. This page explains what is submitted, what the server does with it, and what stays in your browser.

database No database in v1 person_off No accounts update October 2026

What you submit

When you press Run, the browser sends the Java source files currently in the editor to POST /api/run. The server uses that source to compile and execute the program in a sandbox. The source is not written to a database and is not tied to an account.

What the server produces

The runner returns an execution trace: method calls, assignments, returns, source locations, and captured stdout. The trace is sent back to your browser. The server does not keep a persistent run history.

delete_sweep

Ephemeral by design

The runner works inside a temporary workspace and removes it after the job. The current build has no user database, saved traces, or shared run history.

What stays in your browser

The site stores your light/dark preference in localStorage. This build does not save submitted source or run traces in browser storage. If an older version of the site left a codexonia-trace entry in your browser, you can clear site data to remove it.

Sandbox isolation

Student code runs in a Docker container with no network, a read-only root filesystem, all Linux capabilities dropped, and a non-root user. CPU, memory, process count, output size, and wall-clock time are bounded. The host Spring Boot process never executes student code in-process.

Read the exact defaults in the field guide.

Audio

The deterministic tone mapping is computed from event signatures. When the browser player is enabled, audio is generated locally with the Web Audio API. The site does not request microphone access and does not record audio.

Third-party assets

The pages load fonts from Google Fonts, utility styles from the Tailwind CDN, and the editor from the CodeMirror CDN. Those requests are made directly by your browser to those providers and are subject to their own policies. They are used for presentation and editing, not for analytics.

public

CDN dependency

If you need a fully self-contained deployment, vendor the font, Tailwind, and CodeMirror assets instead of loading them from third-party CDNs.

What we do not do

  • No account creation or login.
  • No advertising or behavioral analytics in this build.
  • No selling or sharing of submitted source.
  • No persistent student trace database.

Changes

If the retention model changes, this page and the project specification must change with it. The current implementation follows the “no database in v1” constraint recorded in the architecture notes.
